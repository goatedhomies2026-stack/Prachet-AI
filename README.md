# Prachet AI Studio 🚀

A sleek, lightweight, single-file AI Studio web application powered by **Groq** for high-speed LLM inference and **Tavily** for real-time web search. Built with a modern dark UI, it runs entirely in your browser with zero backend setup required.

### Key Highlights
- **Lightning-Fast AI Engine:** Direct integration with Groq's low-latency Llama 3.3, Llama 3.1, and Mixtral models.
- **Real-Time Web Search:** Toggle live web retrieval powered by Tavily AI Search for grounded answers.
- **Multi-Format File Analysis:** Drag and drop PDFs, code files, JSON, or plain text directly into chat context.
- **Flexible Persona Switching:** Easily toggle between developer, researcher, copywriter, or custom system prompts.
- **Interactive Chat Controls:** Edit previous prompts mid-conversation, regenerate responses, dictate prompts via voice input, and export full chats as Markdown.
- **Privacy-Centric:** All API keys, user credentials, and chat histories are stored strictly in your browser's local storage.
